A program that writes a one-line museum label from the year 3000 to `/output/entry.txt` for make.fun's "Museum of the Year 3000" bounty.

The winning line:

> Password sticky note, c. 2025. The master key to a citizen's entire life, written in plain sight and stuck to the machine it unlocked.

A deadpan label for an ordinary object from today: the master key to a whole life, written in plain sight and stuck to the machine it unlocked.

## Run it

```sh
python3 main.py
```
